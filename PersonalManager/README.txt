Personal Manager 1.0
===================
自分専用のTODO・ルーチン・イベント・メモ統合アプリ。

1. Windowsですぐ試す
    同梱の「PersonalManager_単体版.html」をダブルクリックしてください。
    データはブラウザ内に自動保存されます。まず設定 > JSONバックアップを定期保存してください。

2. iPhoneでも使う（PWA）
    このフォルダの index.html / *.js / *.css / *.png / sw.js / manifest.webmanifest を
    HTTPS対応の静的ホスティング（Cloudflare Pages、GitHub Pages等）へ一括公開します。
    iPhoneのSafariで公開URLを開き、共有メニュー > ホーム画面に追加。
    Windowsでも同じ公開URLを開くことができます。
    ※ HTML単体版のダブルクリックは端末ごとのデータ保存のみで、iPhoneとは同期しません。

3. Windows / iPhone間で自動同期
    (a) https://supabase.com で自分のプロジェクトを作る
    (b) SQL Editorで supabase.sql を実行する
    (c) Supabaseの Project URL と publishable (または anon) key を
        アプリ内「設定 > クラウド同期」に入力する
    (d) 自分のメールアドレス・パスワードで登録（メール確認が必要な場合あり）しログイン
    (e) iPhone側でも同じアカウントでログインする
    認証設定で自分以外の新規サインアップを無効にすることを推奨します。
    ※ service_role keyは入力禁止。RLSを設定していることが前提です。
    ※ 双方向のリアルタイム共同編集や厳密な競合解決は未実装です。
       同時編集すると後から書き込まれたスナップショットが優先されます。
       端末を切り替える際は再読み込みしてください。

4. 主な機能
   TODO: 完了/取消、期限時刻、備考、カテゴリ、色、検索・絞込、優先度
   ルーチン: 毎日、曜日指定（複数）、毎月、毎年、任意のN日・週間・か月・年ごと、週/月N回
   イベント: 開始/終了日時、会期、カレンダー表示、一覧、場所/URL、カテゴリ色
   メモ: タイトル、本文、カテゴリ、検索、色分け
   履歴: 直近30日/今月/任意期間、達成率・履歴のCSV（Excel対応UTF-8 BOM）
   設定: カテゴリ管理、ダークモード、JSONバックアップ/復元、Supabase同期
   コマンド: 入力欄に「help」と入れて例を参照

5. 注意事項
   * ブラウザのサイトデータ・ストレージを削除すると、クラウド未同期のデータは消えます。
   * CSV出力はデスクトップ/モバイル共通実装ですがPCの利用を想定しています。
   * 達成率はルーチンが対象。週/月N回は集計期間の端で予定回数を日数按分します。
   * 非常に大量の履歴を保存した場合は、処理が重くなる可能性があります。
   * 日付は端末のローカル日付（通常、日本時間）を使います。
   * 単体HTMLではオフライン利用できます。PWA版は初回表示後オフラインで起動可能です。
